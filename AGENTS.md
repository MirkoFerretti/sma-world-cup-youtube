# AGENTS.md

## Project

- Study narrative communities in World Cup YouTube comments.
- Keep sentiment as supporting evidence, not the main contribution.

## Method

- Treat co-commenting as shared participation, not direct interaction.
- Interpret communities with both network structure and comment content.
- Do not create fake data, outputs, or results.

## Code

- Prefer small, explicit, readable functions.
- Use `pathlib` for paths and `src/config.py` for shared configuration.
- Keep raw data and API keys out of Git.
